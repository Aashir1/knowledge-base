# Notes

Interview-prep notes, published with [Fumadocs](https://fumadocs.dev) at https://aashir1.github.io/knowledge-base/.

- Notes live in `content/docs/` as Markdown. Each folder's `meta.json` sets the sidebar order.
- `npm run dev` previews the site at http://localhost:3000/knowledge-base/.
- Pushing to `main` builds and deploys the site through `.github/workflows/deploy.yml`.
